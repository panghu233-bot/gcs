开始编辑你的内容

点击「打开游戏项目」选择游戏根文件夹，自动加载卡牌与升级分支。连接后「卡牌设计」直接显示真实卡牌，可编辑确认的字段和分支数值。编辑只作用于内存副本，可查看差异、撤销、导出草稿；点击「应用修改到游戏」并检查差异、选择项目外备份目录及授权写入后才会覆盖两份 JSON。刷新前请导出未应用草稿；未连接时显示演示卡牌。支持文件夹记忆的浏览器会在下次打开时恢复连接，必要时点击「重新授权」。其他浏览器每次只需重新选择整个文件夹。只记住访问句柄，不缓存游戏数据；断开项目会清除该记忆。

从左侧切换 NPC、剧情和卡牌。NPC 包含人物、出场、英雄玩法与战斗关联标签；NPC 已接入本地养成人物识别与现有 PNG 立绘替换（人物、可找到的立绘、脚本引用和同名敌人）；在「人物形象」选择版本，点击「更换图片」，选择 PNG 后对比新旧图片；先选择项目外备份目录并完成备份校验，再点击「授权写入并替换」。最多 8 MB，单边最多 16384 像素，总像素不超过 6400 万。共用立绘会显示影响人物；缺失图片不能替换。人物资料与事件仍只读。不能识别的内容不使用演示替代。剧情事件连接后自动识别本地养成事件和 Dialogic 时间轴。标记「完整编辑」的直线对白支持文字、增删复制、排序、说话人、左右人物和表情；标记「仅文字」的复杂工厂和分支剧情只允许修改已确认的已有对白、选择提示和选项文字，其他配置保持锁定；动态文字逐项标记只读，完全无法安全定位的来源展示只读原因。修改仅保留在内存，先审阅差异、选择项目外目录完成备份，再授权写入；写后自动重新解析验证。从备份恢复只还原当前事件，保留其他事件的后续修改。切换事件前会提醒未应用草稿。未连接时保留演示工作区；卡牌模块保留原有真实数据编辑与写回。演示表单的修改会在当前浏览器本地自动暂存。

  1. 在 NPC 中修改姓名、背景，点击关联事件进入剧情。
  2. 在剧情中增删、排序对白，设置参与人物和选项目标；点击“试读”亲自选择分支。
  3. 在卡牌中修改属性、所属人物、来源事件和升级目标，右侧卡面同步更新。
  4. 点击“保存 JSON”下载完整项目；在任意浏览器重新导入即可恢复，包括上传的图片。

图片支持 PNG / JPG / WebP，每张最多 2 MB。图片内嵌在 JSON 中。浏览器本地记录不是文件备份，建议导出 JSON。

在线版说明：网页程序公开发布，但你选择的游戏文件只在浏览器本地读取，不会自动上传。修改的演示项目暂存在此浏览器中，不会同步到其他设备或自动写回《凝顾》。请定期导出 JSON 备份；从旧版切换到在线版时，需要先导出再导入。

演示不包含战斗结算、条件表达式、游戏引擎接入、多人协作或版本管理。试读只演示剧情路径，不执行卡牌奖励。

应用修改到游戏

仅对下面两份卡牌 JSON 中已编辑的字段值做局部替换，保留其他原始文本；无法安全定位时拒绝保存。先在游戏项目外创建两份原文件的备份并读回校验，再应用修改。请先关闭游戏和其他正在编辑这些文件的程序。

浏览器不能原子提交两个文件。通常失败会自动回滚；断电、磁盘故障或外部并发修改时，可能需要从备份手动恢复。这里不会自动重试。
