# GCS 0.9.0 · 分级剧情编辑

网站：https://panghu233-bot.github.io/gcs/

连接《凝顾》根目录后，剧情来源现在分为「完整编辑」「仅文字编辑」「只读」。2026-10-23 真实源码核对：60 个来源中，14 个完整编辑、33 个新增仅文字编辑、13 个只读。来源数包含同一事件的多个段落或辅助片段，不是独立剧情数量。

原有 14 段完整编辑保留：指日可待、前夜、夜难成寐、江畔悟剑前后段、严师慈母白天/夜晚、首次授琴、练琴观看①/②（源码临时占位）、芦苇滩及镖局胜败对白。文字、增删复制、排序、说话人、左右立绘和表情的功能不变。

新增 33 个仅文字来源：包括木人试招战前/战后、归家、娘亲授艺、出门、藏雨阁闹事及战后分支、看店三事件、红夜来信、书店救猫、母亲教学与任务、音律考核、茶馆偶遇、芦苇滩/镖局前段、喂猫片段和茶馆委托对白。共开放 371 项已有文字：319 项对白、21 项选择提示、31 项选项。逐来源操作和数量见 [能力清单](docs/editor-capabilities.md)。

仅文字编辑不重建事件函数，不改变奖励、战斗、分支、选项归属、跳转、说话人、立绘、表情或背景。字典必须能证明进入返回的对白数组或事件对象的 lines；静态引用链必须能连接到已声明入口。未使用字典、未经确认的别名、变量遮蔽、动态分支归属和未知字典键不会被猜测为可写内容。动态生成的 4 项文字继续逐项只读，同一来源内的其他已确认文字仍可编辑。

对白、选择提示和选项分别绑定函数内稳定文字身份，界面显示源码条件、对白数组、跳转标签或选项去向及源码行。同样的文字出现在不同分支时不会合并。不能确定分支归属、文字由变量/拼接/条件/格式化表达式生成、目标无法确认等情况会显示只读原因；只读源码仍可查看。3 个茶馆分发函数没有自己的文字，1 个旧芦苇滩工厂没有已确认入口，9 个 Dialogic 时间轴格式尚未接入，继续整体只读。

使用：选事件 → 编辑剧本 → 修改开放的文字 → 查看差异并应用 → 选择游戏项目外目录并验证备份 → 授权写入。仅文字来源不显示结构或演出编辑按钮，动态只读项不显示输入框；原有完整编辑来源继续提供全部操作。草稿只在内存，切换或离开前提醒；真实内容不进入演示 JSON。

写入复用现有原文、身份、路径、草稿和执行入口校验，项目外唯一备份、SHA-256 与逐字节验证、提交前冲突复查、写后回读、失败回滚及不确定状态锁定。仅文字补丁只替换用户审阅过的普通字符串字面量，源码中其他字节必须保持不变。只读来源不能借用完整编辑适配器写入。

从备份恢复：在相同来源点击「从备份恢复」，选择具体 gcs-event-backup-* 目录并审阅后确认。仅文字来源使用 v3 文字身份记录，恢复前必须确认当前函数全部非可编辑文字字节与备份一致，拒绝发生奖励、条件、跳转、注释或文字身份变化的恢复；其他函数的后续修改保留。原有完整编辑来源继续兼容 v1/v2 备份。恢复前当前状态仅有内存快照，普通保存仍必须先做磁盘备份。浏览器仍有最终检查与提交之间的并发窗口，应关闭其他源码写入程序。

人物和 PNG 预览继续采用游戏真实映射，只从本地读取；配置不明时明确停止推断。事件定向读取三个来源、四个入口与 timeline/ 下受数量、深度和大小限制的 .dtl，不扫描其他私人目录。读取、编辑、预览、备份和恢复不向外部服务上传游戏内容。

验证：完整功能与新文字能力的短测试覆盖来源身份、相同文字跨分支、逐项锁定、字面量外字节保持、v3 备份、不同事件拒绝、篡改/冲突/故障回滚、界面保存及恢复，以及 NPC/卡牌回归。全部 47 个可编辑来源用真实源码隔离副本完成连续保存、重新读取、恢复和其他事件修改保留；371 项新增文字逐一验证字符串外字节保持，原有 136 次立绘读取核对通过。正式源码哈希不变。无界面 Edge 验证 60 个来源、26 名 NPC、42 张卡，教学对白、分支选项、动态项锁定与完全只读均正常，页面无脚本错误，所有内容请求仅到本机。

复现：`npm test`；`npm run verify:events -- --project <Godot根目录>`。后者只读正式项目，所有写入在系统临时目录中的隔离副本完成并清理。发布内容不包含真实对白、PNG、项目副本或私有验证截图。原生目录/权限弹窗及 Godot 内最终播放仍未自动验收，本轮没有操纵 Windows 桌面，也没有修改 Godot 项目文件。
