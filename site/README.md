# GCS 0.10.0 · 可视化分支剧情编辑器

[打开网站](https://panghu233-bot.github.io/gcs/)

保留现有三栏：真实事件列表、剧本与分支流程、真实人物演出预览。连接本地《凝顾》项目后使用；游戏源码、图片和备份不会随网站发布或上传。

2026-10-23 核对共 60 个源码来源：原有 14 个完整编辑来源、33 个字面量文字来源、13 个只读来源均保留。来源包含同一事件的不同段落，不能等同于独立剧情事件数。

22 个来源支持可点击的流程视图，其中 15 个包含玩家选择，7 个展示条件或动态构造片段。连续对白、选择、门槛判断、战斗、标签、结束和未知片段分别显示；点击后只编辑该段，不把不同分支对白拼接。没有证据的跨片段连接保持未知。

芦苇滩前段额外支持选择结构编辑：每个选择保留 1–12 个纯文字选项，可新增、删除、排序并连接到同数组中已确认的后续标签。也可分别改选择提示和分支对白。不会新建标签、增删分支对白段或改战斗、奖励和运行播放器。其他 14 个玩家选择来源只开放原有文字权限，明确禁用结构操作。

使用：选真实事件 → 点击流程节点 → 编辑剧本 → 改允许的文字或选项 → 查看全部差异 → 选择项目外目录并验证备份 → 授权写入 → 重新读取。右栏沿用真实人物及表情预览。线性事件继续原有编辑方式。

保存保留源文件与入口冲突检查、草稿复核、项目外唯一备份、SHA-256 校验、写后逐字节验证、失败回滚和不确定状态锁定。结构差异逐项展示选项顺序、文字和去向；v4 备份恢复只替换当前事件，其他函数的后续修改保留。原有 v1/v2/v3 备份继续兼容。

结构编辑与流程连接要求当前播放器、宿主的静态标记 SHA-256 与已核对契约一致。运行代码变化后自动锁定结构、取消运行连接确认，保留旧文字能力。不执行 GDScript 来推断分支。完整范围及技术限制见 [能力清单](editor-capabilities.md)。

验证：全部自动测试及原有 NPC、卡牌、文字与完整编辑回归；47 个真实来源均在隔离磁盘副本完成保存、回读、再次保存和恢复，覆盖 371 项文字、136 次立绘检查。Edge 无界面浏览器验证真实芦苇滩的节点点击、选项增删排序与改连、分支对白、立绘、差异、备份保存和恢复。读取的正式游戏文件哈希未变。原生目录授权弹窗及 Godot 内实际播放仍属于待人工测试。

开发检查：使用 Node 22 或更新版本运行 npm test。真实来源隔离验证：node tools/verify-events.cjs --project <Godot根目录>。浏览器验收使用本机 Playwright 与 Edge：node tools/verify-flow-browser.cjs --project <Godot根目录>。只读读取正式项目，磁盘写入均由工具创建的临时副本承担。
