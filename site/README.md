# GCS 0.11.1 · 连续剧情阅读与安全编辑

[打开工作台](https://panghu233-bot.github.io/gcs/)

打开真实剧情后，标题下方直接显示开场。对白按已确认的顺序连续排列，选择出现在正文里：点击选项后，其后续立即在下方展开；改选另一项只切换后续，开场不会重复。条件、战斗结果与已确认奖励使用简明中文说明，结束明确标记。

默认不展示流程图、源码路径、函数名或原始配置。流程图通过“查看流程图”单独打开，返回后保留阅读中的选择。技术限制和真实源配置集中在默认折叠的“高级信息”。未确认的连接会暂停阅读；未接入正文的内容放进独立折叠片段，不冒充完整故事。

《老人典当》先完整显示五句开场，再显示“要不要帮助他？”。“出手收下”展开三句实际后续；“拒绝收下”按当前源码显示结束，不会拼接未接入的拒绝对白。铜炉真伪、娘亲授艺、芦苇滩及普通线性剧情均纳入真实浏览器验收。

《茶馆偶遇》现在可直接切换“遇见万钧”“遇见迦南”和“其他人物 · 暂无对白”，各自按真实返回顺序阅读。条件情况与玩家选项使用不同控件，切换不会清除编辑草稿。相同能力覆盖四个战后来源的胜败情况、猫儿再会的带鱼与未带鱼情况，以及街巷遇猫的四种开场状态。跨段调用未完整接入时明确暂停并提供独立入口，不擅自拼接。所有无法确认顺序的备用内容改用说话人和对白摘要命名。

点击“编辑剧本”即可直接在正文选择对白或修改提示、选项文字，无需寻找图节点。14 个完整编辑来源保留增删、复制、排序及人物演出设置；33 个文字来源只开放原有已确认字段，合计 47 个可编辑来源没有减少。芦苇滩的选择结构编辑继续保留，可从流程图中增删、排序及修改已确认的连接。右栏仍使用本地真实立绘与表情。

保存流程不变：正文修改 → 查看全部差异 → 选择项目外目录并验证备份 → 授权写入 → 重新读取。保留冲突检查、写后逐字节验证、失败回滚、恢复与能力边界。阅读只用于查看剧情，不执行战斗、条件判定或发放游戏奖励；查看战斗胜败结果也不会修改游戏状态。

正式游戏只读，所有实际写入验收均使用临时隔离副本。网站与仓库不包含私人立绘、游戏源码、备份或验收截图。NPC、卡牌及旧编辑和写回测试继续通过。
