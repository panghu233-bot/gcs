开始编辑你的内容

从左侧切换 NPC、剧情和卡牌。所有表单可直接编辑，修改后在当前浏览器本地自动保存。

  1. 在 NPC 中修改姓名、背景，点击关联事件进入剧情。
  2. 在剧情中增删、排序对白，设置参与人物和选项目标；点击“试读”亲自选择分支。
  3. 在卡牌中修改属性、所属人物、来源事件和升级目标，右侧卡面同步更新。
  4. 点击“保存 JSON”下载完整项目；在任意浏览器重新导入即可恢复，包括上传的图片。

图片支持 PNG / JPG / WebP，每张最多 2 MB。图片内嵌在 JSON 中。浏览器本地记录不是文件备份，建议导出 JSON。

在线版说明：网页程序公开发布，但你选择的卡牌文件只在浏览器本地读取，不会自动上传。修改的演示项目暂存在此浏览器中，不会同步到其他设备或自动写回《凝顾》。请定期导出 JSON 备份；从旧版切换到在线版时，需要先导出再导入。

演示不包含战斗结算、条件表达式、游戏引擎接入、多人协作或版本管理。试读只演示剧情路径，不执行卡牌奖励。
